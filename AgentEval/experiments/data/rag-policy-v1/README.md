# 模拟政策包 v1

10 份店铺政策，24 个问题族草案：16 个开发题族、8 个保留题族。均由 Codex 编写，用于实验，不是真实店铺承诺或人工金标。

`public-pack.json` 是开发用 API 的唯一来源；包含原文、必要事实、覆盖矩阵与教学故障派生说明。`holdout-draft.json` 不通过这个 API 返回。保留题是**同政策新情境**，不能据此声称未见政策泛化。它们尚未按真人研究协议冻结；开发者能读取服务器文件，不提供考试防作弊保证。

事实映射默认 DRAFT，source=CODEX。界面需由实际审核人核对必要事实和参考答案后声明 CONFIRMED，才计入已审核覆盖；审核参考答案的 SHA-256 同时固定，修改答案后不再作为已审核 DeepEval 参照。

不把未知订单状态写成政策事实。澄清、诚实说明不支持、转交与任务完成分别判断。模型与自动位置匹配不能替代业务审核。

不在训练、提示词、回答生成器或上下文组装器中使用参考答案和必要事实标签。事实审计发生在检索之后。教学故障属于植入错误，必须与自然失败分开报告。
