# Agent Eval 前端

Vue 3 / Vite，Agent Eval 的独立前端。主导航按「准备 → 看结果 → 试修改 → 看变化 → 整理项目」组织，到此即可完成项目；侧栏底部「检查 AI 打分 · 进阶」是按需使用的工具。

当前流程：连接模型 → 准备资料与题目 → 逐题看结果 → 选择改法并复测 → 比较与决定 → 整理项目。生成题目后直接显示在下方；资料和题目支持一键清空与撤销。完整日志一次复制，也可下载完整文件，不再要求分段复制或填写外部建议。详见 [更新记录与验证边界](../CHANGELOG.md)。

主要包含逐题结果与运行日志、十种改法的本题方案、新手原理图解、CSV 导出和项目整理提问。「复制提问给 AI」可用于分析单题改法、检查原评分、整理项目求职表达，内容均在浏览器本地准备。

试修改默认先快速试跑当前题，前后回答与评分直接显示在方案下方。用户看过单题效果后，再单独启动全部原题复测；更改题目、模型连接或方案参数后须重新试本题。单题运行单独存档，不进入整批统计。整批最多 3 题并行，各题独立保存 SDK 返回、用量与日志，共用原请求上限。「连同前后文一起读」不要求选择补全参数，默认补上相邻原文；如果初测已经采用相邻补全，则试一次只读查到的内容，页面会说明实际变化。切块、索引等技术解释保留在问号中；补全前后文沿用已有 chunk 和索引，调整切块才重新切分文档、建立索引。

结果中，每道题的评分旁都有「检查这次评分」。打开即带入当前题的问题、原回答、当时的参考资料、评分理由和评分细则，点击「复制提问给 AI」后粘贴到常用 AI。无需先导入文件、创建分类、填写操作人或搜索历史记录。复制不请求模型，也不更改原判；材料过长或缺失时会注明。

进阶入口只展示两种用途：检查单题原判、人工与 AI 对照。批量重评与定期检查另有次级入口。进入检查首页不会读取历史实验；只有明确选择历史记录才读取。本站重评、人工复核仍由用户另行发起，AI 建议不会自动成为人评。

进入页面不会自动恢复旧实验。有记住的实验时，先选择「开始新实验」「继续上次实验」或「从历史实验中选择」。继续读取最多等待 20 秒，支持取消；读取失败或取消后可以开始新实验，旧记录仍保存在服务器历史中。未作出选择前，浏览首页和练习不会覆盖记住的实验入口。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

开发站点默认 `http://127.0.0.1:5173`，`/api` 代理至 `http://127.0.0.1:8000`。完整运行、独立后端和浏览器测试配置见 [Agent Eval 说明](../README.md)。历史阶段说明保留在 [LEGACY_README.md](LEGACY_README.md)。


本轮浏览器验收（隔离脚本模型与真实本地后端）：

```sh
AGENTEVAL_TEST_PYTHON=/absolute/path/to/python pnpm exec playwright test -c playwright.ux.config.js
```

`AGENTEVAL_TEST_PYTHON` 需能导入根目录的 `requirements-runtime.txt` 与 pytest；不会读取商业模型 Key。运行报告与截图集中在 `output/ux-implementation-20261030/`。流程/原文选择/导出/比较口径测试在 `tests/ux-flow.test.js`，后端流程恢复测试在 `AgentEval/tests/test_retest_flow.py`。

补资料支持「AI 整理并补充到知识库 → 查看新增内容 → 返回本题复测」。只保存原参考答案，不把 AI 新猜测作为政策；备注、观察目标、风险选择和「其他改法与高级参数」已从修改表单移除。

本地界面以手绘风格图解呈现修改步骤；比较页先显示变化数量与逐题判定卡片。完整回答、依据、用量和执行记录可展开查看，完整日志复制与项目求职提问保留。

程序更新不会阻止单题探索：本题按当前程序试跑，旧评分仅作参考，日志标记不可直接比较；完成试跑后再提示更新初测以进行正式整批比较。

回答阅读区统一支持 Markdown：加粗、标题、编号与项目列表、引用、表格及代码块；覆盖原回答、试跑、前后比较、评分引用和复核材料。只转换显示，复制与完整日志仍使用保存的原文；不执行回答里的 HTML，也不自动加载远程图片。

「看变化」支持已保存的单题试跑：无需整批报告即可展示对应题目的新旧回答、评分、资料新增与移出，并保留完整试跑日志。试跑结果也提供「查看本题变化」入口。只展示与当前初测绑定的实际题目，旧程序评分仅供参考；正式整批比较继续使用独立报告和原有统计。
