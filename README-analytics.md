# Agent Eval 访问与使用统计

项目内置第一方统计模块，了解工作台的访问、功能使用和流程完成情况。后端使用 SQLite，前端仅发送固定白名单事件。

## 统计内容

| 指标 | 含义 |
| --- | --- |
| 浏览量 | 进入或切换固定页面的记录，包含刷新。 |
| 匿名访客 | 按匿名浏览器工作区去重，不等于真实人数；换设备、无痕或清除 cookie 会形成新身份。 |
| 访问次数 | 以 30 分钟无活动作为新访问边界，不采集按键内容和指针轨迹。 |
| 核心功能使用 | 已完成的保存、评测、修改、比较等操作，按服务器返回的实际结果记录。 |
| 导出行为 | 取得导出内容、复制成功、触发下载分别记录；触发下载不证明最终保存。 |
| 流程与失败 | 区分开始、成功、失败、部分完成和未知，便于发现使用阻塞。 |

“功能成功”表示操作完成，不代表回答正确、评分可靠或求职成功。只浏览和复制材料，也不等于完成实验。

## 排除自己的测试

在站点页脚的「统计设置」中排除当前浏览器。每个浏览器分别设置，清除 cookie 后需重新设置。排除统计不删除业务历史。

## 配置与数据

未配置统计目录时，统计存储不启用。启用时为后端设置 `AGENTEVAL_ANALYTICS_DIR`，统计与业务实验分开保存。

私有汇总访问使用 `AGENTEVAL_ANALYTICS_TOKEN_FILE` 指向的本机凭据文件，不能提交到仓库或公开静态站点。生产环境应在反向代理限制报告查询，仅公开必要的事件提交入口。仓库不提供任何部署环境的查询凭据。

前端事件合同见 `AgentEvalFrontend/src/analytics-contract.js`，后端见 `AgentEval/experiments/analytics.py` 与 `analytics_contract.json`。事件使用固定字段，不应携带模型 Key、问题、回答或用户输入正文。

历史未采集的维度显示未知，不从当前事件倒推过去的浏览量或访客。业务记录可用于检查保存、运行等已发生操作，不能补造历史曝光和点击。
